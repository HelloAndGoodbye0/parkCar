## 2. 整体架构

采用前后端分离的经典分层架构：

```
┌─────────────────────────────────────────────────┐
│                  浏览器（Vue3 管理端）            │
└───────────────────────┬─────────────────────────┘
                        │ HTTPS / RESTful JSON
┌───────────────────────▼─────────────────────────┐
│                  Nginx（反向代理/静态资源）        │
└───────────────────────┬─────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────┐
│                后端服务（Spring Boot）            │
│  ┌─────────┬─────────┬─────────┬─────────────┐  │
│  │ Controller│ Service │ Mapper  │ 定时任务    │  │
│  │ 层        │ 业务层   │ 数据层   │ (统计/过期) │  │
│  └────┬─────┴────┬─────┴────┬────┴──────┬─────┘  │
│  JWT 鉴权过滤器   │          │          │        │
└─────────┬─────────┼──────────┼──────────┼────────┘
          │         │          │          │
     ┌────▼────┐ ┌──▼───────┐ ┌▼─────────┐ ┌▼──────────┐
     │  MySQL   │ │  Redis    │ │ 文件存储  │ │ 日志系统   │
     │ 主数据库 │ │ 缓存/锁   │ │ 照片等    │ │ (Logback)  │
     └─────────┘ └──────────┘ └──────────┘ └───────────┘
```

### 分层职责

| 层 | 职责 |
| ---- | ---- |
| Controller 层 | 参数校验、鉴权、请求分发、统一响应封装 |
| Service 层 | 业务逻辑：计费、出入场事务、车位状态流转 |
| Mapper 层 | 数据库访问（MyBatis-Plus） |
| 定时任务 | 每日营收汇总、月卡过期处理、车位状态巡检 |
| 基础设施 | Redis（缓存+分布式锁）、文件存储、日志 |

## 4. 核心业务流程

### 4.1 车辆入场

```
收费员录入车牌(或识别) → 校验黑名单(预警) → 判断是否月卡车辆
  → 是：关联月卡记录，直接入场
  → 否：选择/自动分配空闲车位
  → 创建在场车辆记录(状态=在场)，车位状态置为占用
  → 返回入场结果
```

### 4.2 车辆出场

```
输入车牌查询在场记录
  → 未找到：提示异常（手工入场）
  → 找到：
      计算停车时长 → 按月卡？(有效期内免费/按规则)
      按收费规则计算应收金额
      收费员收款（现金/微信/支付宝）→ 允许减免/改价
      生成订单+支付流水
      车位状态置为空闲，车辆记录完结(状态=已离场)
```

### 4.3 数据一致性约束

- 车位状态与在场车辆记录必须一致：入场时事务内先占车位再落在场记录；
- 出场结算使用 Redis 分布式锁防止同一车牌重复出场；
- 计费金额以数据库时间为准，避免多实例时钟偏差。

## 5. 关键设计点

1. **车位分配策略**：支持手动选择与"自动分配"（优先同区域空闲车位）。
2. **计费引擎**：独立 `BillingService`，按「规则配置」驱动，支持规则版本化（历史订单按当时规则结算）。
3. **在场车辆与车位状态**：`parking_records` 表 `status='IN'` 表示在场；车位表冗余 `status` 字段用于快速查询，通过事务保证一致。
4. **软删除与审计**：所有业务表保留 `deleted` 逻辑删除标记；关键操作写 `operation_logs`。
5. **异常处理**：统一响应体 `{ code, message, data }`；全局异常拦截器。

## 6. 接口约定

- 全部接口路径前缀 `/api`
- 认证方式：请求头 `Authorization: Bearer <JWT>`
- 分页参数统一：`page`（从 1 开始）、`size`
