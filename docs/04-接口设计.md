# 04 接口设计

## 1. 通用约定

### 1.1 基础信息

- 基础路径：`/api`
- 数据格式：JSON（UTF-8）
- 认证：请求头 `Authorization: Bearer <token>`（登录接口除外）

### 1.2 统一响应体

成功：

```json
{ "code": 0, "message": "success", "data": { } }
```

失败：

```json
{ "code": 40001, "message": "车牌已在场，不能重复入场", "data": null }
```

| code | 含义 |
| ---- | ---- |
| 0 | 成功 |
| 40000 | 参数错误 |
| 40100 | 未认证 / token 失效 |
| 40300 | 无权限 |
| 40400 | 资源不存在 |
| 40900 | 业务冲突（如重复入场） |
| 50000 | 服务器内部错误 |

### 1.3 分页

- 请求参数：`page`（从 1 开始，默认 1）、`size`（默认 10，最大 100）
- 响应 `data`：

```json
{
  "total": 100,
  "pages": 10,
  "current": 1,
  "records": [ ]
}
```

### 1.4 公共枚举

| 枚举 | 值 |
| ---- | ---- |
| 车位状态 | 0=空闲 1=占用 2=禁用 3=维护 |
| 车位类型 | 0=普通 1=充电 2=无障碍 3=VIP |
| 停车记录状态 | 0=在场 1=已离场 2=异常 |
| 支付方式 | 1=现金 2=微信 3=支付宝 4=月卡抵扣 |
| 订单状态 | 0=待支付 1=已支付 2=已取消 |
| 角色编码 | ADMIN=管理员 OPERATOR=收费员 |

### 2.7 车辆入场 `/api/records/in`

| 方法 | 路径 | 说明 | 权限 |
| ---- | ---- | ---- | ---- |
| POST | /api/records/in | 车辆入场 | OPERATOR/ADMIN |
| GET | /api/records/current | 在场车辆分页查询 | 登录用户 |
| GET | /api/records/current/{plateNo} | 按车牌查询在场记录 | 登录用户 |
| GET | /api/records | 历史记录分页查询（按车牌/时间） | 登录用户 |
| POST | /api/records/{id}/manual-out | 手工出场（异常补录） | OPERATOR/ADMIN |

**POST /api/records/in**

```json
// 请求
{
  "plateNo": "京A12345",
  "spaceId": 101,          // 可选，不传则自动分配
  "areaId": 1,
  "remark": "临时车"
}

// 响应 data
{
  "recordId": 80001,
  "plateNo": "京A12345",
  "spaceNo": "A-001",
  "inTime": "2026-08-18 09:30:00",
  "isMember": false,
  "inBlacklist": false,     // true 时前端弹出黑名单预警
  "autoSpace": false        // 是否系统自动分配车位
}
```

**错误场景**

- `40901` 车牌已在场
- `40401` 车位不存在或已被占用（手动指定时）
- `40902` 无可用车位（自动分配失败）

### 2.8 车辆出场 `/api/records/out`

| 方法 | 路径 | 说明 | 权限 |
| ---- | ---- | ---- | ---- |
| POST | /api/records/out/preview | 出场预览（查询+试算金额，不落单） | OPERATOR/ADMIN |
| POST | /api/records/out/settle | 出场结算（生成订单并完成） | OPERATOR/ADMIN |

**POST /api/records/out/preview**

```json
// 请求
{ "plateNo": "京A12345" }

// 响应 data
{
  "recordId": 80001,
  "plateNo": "京A12345",
  "inTime": "2026-08-18 09:30:00",
  "outTime": "2026-08-18 15:40:00",
  "durationMinutes": 370,
  "isMember": false,      // 入场时是否月卡车辆（快照）
  "memberFree": false,    // 出场时实时校验：有效月卡为 true（免费放行）
  "spaceNo": "A-01",
  "rule": {
    "ruleId": 3, "name": "标准计时", "ruleType": 0,
    "freeMinutes": 15, "firstHourFee": 5.00,
    "hourlyFee": 3.00, "maxDailyFee": 30.00
  },
  "amount": 21.00,       // 应收
  "feeItems": [          // 收费明细（白天/夜间/按次/免费）
    { "type": "DAY",  "period": "08-18 09:30 ~ 08-18 15:40",
      "desc": "6小时25分钟", "amount": 21.00 }
  ],
  "discount": 0,
  "payableAmount": 21.00 // 实收
}
```

`feeItems.type` 取值：`DAY` 白天（按时计费，按自然日切分，逐日一条）、`NIGHT` 夜间（每覆盖一晚一条）、`ONCE` 按次、`FREE` 免费（月卡/免费时长内）。`desc` 在命中每日封顶时附带"（已达每日封顶 ¥xx）"说明。

**POST /api/records/out/settle**

```json
// 请求
{
  "recordId": 80001,
  "plateNo": "京A12345",
  "payType": 2,           // 1现金 2微信 3支付宝 4月卡抵扣
  "discount": 0,          // 减免金额（可选项，需权限）
  "remark": ""
}

// 响应 data
{
  "orderNo": "2026081815400012345",
  "recordId": 80001,
  "amount": 21.00,
  "discount": 0,
  "paidAmount": 21.00,
  "payType": 2,
  "outTime": "2026-08-18 15:40:00",
  "spaceNo": "A-001"      // 已释放
}
```

**错误场景**

- `40402` 未找到在场记录
- `40903` 该车辆正在结算中（并发保护）

### 2.9 收费规则 `/api/billing-rules`
