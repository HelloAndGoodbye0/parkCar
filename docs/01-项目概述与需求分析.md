# 01 项目概述与需求分析

## 1. 项目背景

随着城市机动车保有量持续增长，停车难、乱停车问题日益突出。许多中小型停车场仍采用人工登记、手工计费的方式，存在以下痛点：

- 出入场登记效率低，高峰期排队严重；
- 人工计费易出错，收费标准不透明，易引发纠纷；
- 缺少车位实时状态监控，车位利用率低；
- 收费明细、营收数据缺乏系统化记录，难以统计与审计。

本项目旨在开发一套轻量、易用、可扩展的停车管理系统，覆盖停车场日常运营的主要环节。

## 2. 项目目标

1. 实现车辆出入场的信息化登记与自动计费；
2. 提供车位实时状态管理与可视化查询；
3. 支持多种收费规则（按时、按次、免费时长、封顶价等）；
4. 支持会员/月租车管理，支持多种支付方式（现金、微信/支付宝）；
5. 提供营收统计与运营报表，辅助管理决策；
6. 系统易部署、易维护，支持后期扩展（车牌识别、道闸联动等）。

## 3. 用户角色

| 角色 | 说明 | 主要权限 |
| ---- | ---- | -------- |
| 系统管理员 | 停车场运营方 | 全部功能：车位/规则/人员/套餐管理、报表查看 |
| 收费员（值班员） | 现场操作人员 | 车辆出入场登记、收费结算、异常处理 |
| 车主（普通用户，可选） | 停车消费者 | 查询缴费、月卡续费（小程序/公众号端，二期） |

> 一期以管理端（管理员 + 收费员）为主，车主端作为可选扩展。

## 5. 非功能需求

| 类别 | 要求 |
| ---- | ---- |
| 性能 | 常规操作响应 < 1s；支持并发出入场操作，支撑单场日流量 2000+ 车次 |
| 可用性 | 核心接口可用性 99.9%；数据每日备份 |
| 安全 | 密码加密存储（BCrypt）；JWT 鉴权；操作权限隔离；敏感数据脱敏 |
| 易用性 | 操作界面简洁，出入场操作 3 步内完成，支持键盘快捷键（可选） |
| 可扩展性 | 模块化设计，预留车牌识别、道闸联动、车主端接口 |
| 兼容性 | 主流浏览器（Chrome / Edge / Firefox）最新版本 |
| 可靠性 | 计费规则变更可追溯；数据一致性（车位占用与在场车辆强一致） |

## 6. 需求边界（一期不做）

- 车主端小程序/公众号（二期）
- 硬件对接：车牌识别、道闸、地锁联动（二期）
- 多停车场/多门店连锁管理（二期）
- 发票管理、电子对账（二期）
