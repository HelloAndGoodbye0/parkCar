# 03 数据库设计

## 1. 设计约定

- 数据库：MySQL 8.0，字符集 `utf8mb4`，排序规则 `utf8mb4_general_ci`
- 表名/字段：小写下划线命名
- 主键：`id BIGINT`，自增
- 通用字段：`create_time`、`update_time`（自动填充）、`deleted`（逻辑删除，0=正常 1=删除）
- 金额字段：`DECIMAL(10,2)`，单位元
- 时间字段：`DATETIME`
- 索引：为常用查询字段（车牌、状态、时间）建立索引

> 说明：建表脚本见 `sql/init.sql`，本设计文档以该脚本为准。

## 2. ER 关系总览

```
sys_user ──< operation_log
sys_user ──< sys_user_role >── sys_role
sys_user ──< sys_user_area >── parking_area（数据权限：收费员负责的区域）

parking_area ──< parking_space
parking_area ── billing_rule（billing_rule_id 绑定收费规则，NULL=全局默认）
parking_space ──< parking_record（在场时通过 space_id 关联）

parking_record ──< billing_order（0..1）
billing_order ──< payment_record（1:N）

membership_package ──< membership_card ──< parking_record（通过车牌/卡关联）
billing_rule / blacklist / daily_report（独立表）
```

## 5. 计费算法说明（供开发参考）

计费引擎入口为 `BillingService.calculateDetail(inTime, outTime, rule, freeFlag)`，返回总额 + 逐项明细（`BillingDetail`），供出场试算/结算复用。免费时长判断优先级最高：月卡有效期内（`freeFlag=true`）或总时长 ≤ `free_minutes` 直接免收。月卡有效性以**出场时实时校验**为准，入场时的月卡状态仅作快照展示。

### 按时计费（按自然日切分，每日独立封顶）

规则：免费 `free_minutes` 分钟；超出后首小时 `first_hour_fee`，之后每小时 `hourly_fee` 向上取整；按自然日（00:00 为界）切分，**每天独立计费并各自套用 `max_daily_fee` 封顶**；免费时长优先从入场起的第一个日段扣除。

```
total_fee = 0
free_remain = free_minutes
cursor = inTime
while cursor < outTime:
    day_end = 次日00:00（若超出 outTime 则取 outTime）
    seg_minutes = day_end - cursor
    if free_remain > 0:
        seg_minutes -= min(free_remain, seg_minutes); free_remain 递减
    if seg_minutes > 0:
        hours = ceil(seg_minutes / 60)
        seg_fee = (hours == 1)
                  ? first_hour_fee
                  : first_hour_fee + (hours - 1) * hourly_fee
        if max_daily_fee is not null and seg_fee > max_daily_fee:
            seg_fee = max_daily_fee
        total_fee += seg_fee
    cursor = day_end
```

> 例：8-18 15:02 入场、8-21 10:02 出场（67h），`first_hour_fee=5 / hourly_fee=3 / max_daily_fee=30 / free=15` → 4 个日段分别为 29 + 30 + 30 + 30 = **119 元**。每日封顶为"当天重新起算"的口径，多天停车每天各封顶一次。

### 按时 + 夜间计费

配置 `night_start / night_end / night_fee`（开始/结束/费用须同时为空或同时非空；仅按时计费支持，按次不支持）：

- 停车时段每覆盖一个夜间区间（每晚）计一笔 `night_fee`，支持跨午夜（如 22:00~06:00），跨午夜区间按"开始日"归属，只停后夜（如 05:00~05:30）也能命中；
- 白天部分按自然日切分，每天剔除夜间分钟后按按时规则计费，**各自套用每日封顶**；
- 免费时长优先从入场起的白天时段扣除。

```
total_fee = 夜间笔数 * night_fee + 各日段白天费用之和
```

### 按次计费

```
if minutes <= free_minutes: fee = 0 else fee = first_hour_fee（即单次费用）
```

### 月卡车辆

出场试算/结算时**实时校验**月卡有效性：有效期内免费（订单金额为 0，pay_type=4 月卡抵扣）；过期或未办理按普通规则计费。入场时记录的 `parking_record.is_member/card_id` 仅作快照展示，出场结算后更新为本次实际结算状态。
