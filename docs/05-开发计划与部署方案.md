# 05 开发计划与部署方案

## 1. 里程碑计划

| 阶段 | 周期 | 交付物 | 说明 |
| ---- | ---- | ---- | ---- |
| M1 准备与初始化 | 第 1 周 | 前后端骨架、数据库初始化脚本、CI 基础 | 搭好工程，可运行空壳 |
| M2 系统管理 | 第 2 周 | 登录认证、用户/角色管理、操作日志 | 权限体系打通 |
| M3 基础资料 | 第 3 周 | 区域、车位维护与总览 | 数据基础 |
| M4 核心出入场 | 第 4-5 周 | 入场、在场查询、出场试算、结算 | 核心业务闭环 |
| M5 收费体系 | 第 6 周 | 收费规则、订单流水、减免改价 | 计费完整 |
| M6 会员月卡 | 第 7 周 | 套餐、办卡、续费、月卡出场 | 一期简化版 |
| M7 统计报表 | 第 8 周 | 营收/车流/利用率、Excel 导出 | 报表 |
| M8 联调测试与上线 | 第 9-10 周 | 全量测试、性能压测、部署上线 | 稳定发布 |

> 总计约 10 周（2~3 人团队）。单人开发可压缩至 6~8 周，优先保证 M2-M5。

## 4. 部署方案

### 4.1 单机部署（推荐一期）

```
┌─────────────────────────────┐
│  一台服务器（4C8G + 100G）   │
│  ├── Nginx        (80/443)  │ 前端静态资源 + 反向代理 /api
│  ├── Spring Boot  (8080)    │ jar 方式，systemd 托管
│  ├── MySQL 8.0   (3306)     │ 每日备份 cron
│  └── Redis 7.x   (6379)     │ 缓存/锁
└─────────────────────────────┘
```

### 4.2 部署步骤

1. 后端：`mvn package -DskipTests` 生成 `parkcar.jar`，上传服务器，`systemctl start parkcar`；
2. 前端：`pnpm build` 生成 `dist/`，拷贝至 Nginx `html` 目录；
3. Nginx 配置 `/api` 反向代理到 `127.0.0.1:8080`；
4. 执行 `sql/init.sql`、`sql/seed.sql`；
5. 配置每日凌晨 MySQL 备份（`mysqldump` + crontab，保留 30 天）。

### 4.3 备份策略

- 数据库每日 02:00 全量备份；
- 上传图片等文件存储目录每日增量备份；
- 备份文件异地留存（对象存储/另一台机器）。

## 5. 测试方案

| 测试类型 | 范围 | 工具 |
| ---- | ---- | ---- |
| 单元测试 | 计费算法、日期计算、权限校验 | JUnit 5 + Mockito |
| 接口测试 | 全部核心 API（登录、出入场、结算、月卡） | Postman / Apifox 集合 |
| 集成测试 | 出入场全链路、并发出场、事务一致性 | Spring Boot Test + Testcontainers |
| 性能压测 | 入场/出场/查询接口，目标 TPS ≥ 100 | JMeter |
| UI 测试 | 核心流程冒烟（可选） | Playwright |

关键测试用例（必须覆盖）：

1. 免费时长边界（刚好 free_minutes 分钟）；
2. 首小时/跨小时计费（59 分钟、61 分钟、23:59 跨天）；
3. 封顶价生效；
4. 同一车牌并发出场（分布式锁）；
5. 月卡有效期内出场免费、过期正常计费；
6. 黑名单车辆入场预警；
7. 车位分配并发（两个请求抢同一车位）；
8. 逻辑删除后历史数据仍可查询。
